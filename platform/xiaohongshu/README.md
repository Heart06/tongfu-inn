# 同福客栈 · 小红书小工具适配

基于主站提交 `4de43d98fd6938ce3df707b204daa4e7b2e53301`。仅在本目录构建，不修改 `dist/`，不会触发主站内容更改。

## 构建

依赖 Python 3 + Pillow、Node.js + esbuild。先在本目录执行 `npm install`，Python 环境安装 Pillow，然后在仓库根目录运行：

```sh
python platform/xiaohongshu/build.py
node platform/xiaohongshu/compile.cjs
python platform/xiaohongshu/package.py
```

输出 `release/tongfu-inn-1.0.0.zip`。重复构建可设置 `SKIP_IMAGES=1` 复用已压缩图片；主站图片更新后必须完整重建。

## 适配内容

- 11 份 JSON 数据内联，脚本打包为经典 IIFE，目标 Chrome 61 / ES2017。
- 205 张图片保留；透明人物图集不改变尺寸和裁切坐标；较大背景及照片压缩。
- 资源统一使用平台标准 `./assets/` 相对路径。非标准 media 目录的模拟器版本出现重入场景加载失败，已改回 assets 并通过往返切换复测。
- 档案使用内部路由状态，不依赖容器 URL/history。
- 增补 flatMap、fromEntries、replaceChildren、dialog、flex gap、aspect-ratio 等回退。
- 弹层预留原生状态栏和右上角胶囊空间，避免返回按钮误触平台分享。
- 无需相机、麦克风、位置、头像等权限；移除微信复制入口，拦截外部来源链接。
- 提供横屏 CSS 与竖屏提示；没有实现或承诺强制横屏。
