# 同福客栈

《武林外传》互动博物馆的独立公开网页。访客无需登录 ChatGPT 或 GitHub。

## 体验

从大堂探索客房、女寝、后院与屋顶，翻看空间往事、人物志，或让掌柜带你逛。包含小地图和昼夜切换。

## 本地运行

网站文件在 `dist/`，无需安装前端依赖：

```sh
python3 -m http.server 8000 --directory dist
```

浏览器打开 http://localhost:8000 。

## 更新与发布

- 主编辑版本继续在原站点项目中维护。本仓库是独立发布渠道。
- 将确认后的最新站点完整同步到 `dist/`（包括删除不再使用的资源），提交到 `main`。
- GitHub Actions 自动将 `dist/` 发布至 GitHub Pages。原站点的更新不会自行出现在这里，需要完成同步提交。
- 首次导入的临时分块包由工作流校验 SHA256 后还原成正常文件，后续只需维护 `dist/`。
- 首发来源：站点 V91，源提交 `5e3d0f3a14d60aed58f600c5fc6e691b59c5be59`。
